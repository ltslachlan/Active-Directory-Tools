# Active Directory Tools

PowerShell tools for managing, auditing, and reporting on Active Directory environments.

## 📌 Purpose
This repository provides scripts to assist with common Active Directory administrative tasks, including user management, group auditing, and environment reporting.

## 🛠 Scripts Included
- User and group reporting
- Stale account detection
- OU and structure audits
- Profile and attribute cleanup tools

## 🚀 Usage
Run scripts in a domain-joined environment with appropriate permissions:

```powershell
.\scriptname.ps1
